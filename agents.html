Pour les agents IA

La bibliothèque se lit aussi par un agent : demandez-lui « trouve-moi un outil gratuit pour faire tourner un modèle en local » et il cherche dans les fiches à votre place, avec les liens et les limites de chaque offre.

La skill chercher-library

Une skill est un petit fichier d'instructions qu'un agent charge quand la demande s'y prête. Celle-ci lui apprend où sont les données et comment chercher dedans.

En une commande, pour Claude Code, Codex, Cursor, OpenCode, Gemini CLI et la plupart des agents (il faut Node.js) :

npx skills add Oradixx/AI-library --skill chercher-library -g

L'outil détecte les agents installés et y ajoute la skill pour tous vos projets. Sans -g, elle n'est installée que dans le projet courant.

Ou à la main :

Télécharger la skill (.zip)

Ou lire le fichier : SKILL.md.

  • Claude Code : décompressez le zip dans ~/.claude/skills/ (vous obtenez ~/.claude/skills/chercher-library/SKILL.md), puis relancez Claude Code.
  • claude.ai et l'appli Claude : Paramètres, Capacités, Skills, puis importez le fichier .zip tel quel.
  • Autres agents (OpenCode, Codex, Gemini…) : placez le dossier chercher-library là où l'outil range ses skills, ou collez le contenu de SKILL.md dans ses instructions.

Sans installer quoi que ce soit

Donnez simplement cette adresse à n'importe quel agent qui sait lire le web :

https://oradixx.github.io/AI-library/llms.txt

Il y trouve la description de la bibliothèque et les liens vers les données :

  • llms-full.txt : index compact, une ligne par outil, rangé par rayon et par thème.
  • data/outils.json : fiches complètes (description, cas d'usage, offre, licence, tags).

À savoir

Les cas d'usage ont été rédigés avec une IA à partir de notes, et les offres gratuites changent souvent : vérifiez sur le site officiel avant de compter sur un quota.

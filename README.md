# AI library

Page statique triable : outils tech, design, agents IA, API et routeurs, hébergement, offres gratuites et étudiantes, skills et lectures.

- Données : `data/outils.json` (un objet par outil : `nom`, `theme`, `url`, `tarif`, `statut`, `description`, `offre`, `licence`, `tags`, `source`, `post`).
- Aucune étape de build : `index.html`, `style.css` et `app.js` suffisent. GitHub Pages sert le dossier tel quel.
- Test local : `python3 -m http.server` puis http://localhost:8000.
- Filtres partageables par URL : `#theme=Design%20et%20UI&q=gratuit`.

Les quotas et offres gratuites changent souvent : vérifiez sur le site officiel avant de compter dessus.
